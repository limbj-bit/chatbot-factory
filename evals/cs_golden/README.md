# CS Golden Set (대화 구조 + 내용)

경쟁사(채널형 상품 상담) 대비 **구조·내용**을 같이 벤치합니다.  
뷰티만이 아니라 **전 업종**에 적용합니다.

## 채점 축

| 축 | 무엇을 보나 | 합격 기준 |
|----|-------------|-----------|
| 구조 | 짧은 인트로 → 상품 구분 → (카드) → 끝질문≤1 | 환영 멘트 반복 없음, 2~4문장 |
| 내용-사실 | 학습 상품명·가격·스펙만 | 배송비를 판매가로 쓰지 않음 |
| 내용-설득 | 상품마다 추천 이유 1줄 | “3개 있습니다”만으로 끝내지 않음 |
| 카드 | 매칭 상품 수만큼 카드 | `유니폼 있니`→N장, `진주`→진주만 |
| UI강조 | 말풍선=볼드·불릿(무채), 카드=%·구매만 색 | 말풍선에 색/HTML 남발 없음 |

## Run (오프라인 · 네트워크 없음)

```bash
python scripts/eval_cs_golden.py
```

카드 부착·프롬프트 벤치 문구·가격 가드레일 휴리스틱을 검사합니다.  
실제 LLM 문장 품질은 배포 후 수동/라이브로 같은 표로 채점하세요.
